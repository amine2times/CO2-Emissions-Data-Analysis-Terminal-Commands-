# Foundations Project: Data Literacy Field Notes
This project is looking at the co2 emissions for countries. This data set comes from a climate and energy nonprofit that needs to decide where to direct community protection.
I am answering various questions that are provided to me.
There are 7 different data values in the set with 3 different data types.
Country is string, Iso_code is string, Year is integer, Population is integer, GDP is integer and then co2 is float
Key findings I've found is the data isn't clean because Is noticed there are contients that are labeled under countries and that in turn has gaps in data for iso_code as well as gdp.
An AI literacy takeaway that I had was that sometimes it will give you unesscesary information and you would have to check the method on how the AI gets the answers.
